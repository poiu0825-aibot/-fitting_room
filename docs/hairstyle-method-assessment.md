# 自然換髮型方法評估

目前的手機瀏覽器分割加疊圖無法滿足自然換髮型需求。近鄰背景補色已停用；不得將功能測試通過視為寫實品質通過。

## 可選方法

| 方法 | 已確認能力／條件 | 尚未驗證 | 對原需求的影響 |
| --- | --- | --- | --- |
| 保留目前本機疊圖 | 照片不上傳，手機瀏覽器執行 | 無法自然移除原髮或重建遮住的背景 | 保留隱私要求，但不達成自然換髮型 |
| 自有 GPU 執行 HairFastGAN | 官方為參考照片換髮研究實作；要求 Linux、NVIDIA GPU、CUDA/cuDNN、Python 3.10 與 PyTorch | 實際照片品質、GPU 記憶體需求、模型權重與依賴授權、服務部署成本 | 需要額外 GPU 環境；手機照片若交給伺服器仍屬上傳 |
| 遠端圖片編輯 API | OpenAI 官方 SDK 提供 images/edits，可提交來源圖片、參考圖片與 PNG 遮罩；部分模型支援 input_fidelity | 指定髮型準確度、臉部保真、遮罩外變動、最新價格與資料保留政策 | 需要後端保護 API 金鑰、明確上傳同意及費用上限 |

來源：
- https://github.com/FusionBrainLab/HairFastGAN （README 與程式碼 MIT 授權已查阅；不代表所有權重和依賴已完成授權檢查）
- https://github.com/openai/openai-python/blob/main/src/openai/resources/images.py （只確認介面支援，不代表效果或價格承諾）
- https://openai.com/api/pricing/ 與 https://platform.openai.com/docs/guides/your-data （本環境回應 HTTP 403，最新費用與保留政策尚未核實）

## 下一階段的具體驗收

先以有授權的測試素材做少量比較，不使用使用者照片。案例包含正面短髮、長髮改短髮、戶外複雜背景、眼鏡以及不同參考角度。檢查臉部身分、髮際線、髮型尺寸與遮擋、原髮殘留、背景修復及失敗回報；另记录每次耗時與實際費用。測試素材不進 Git。

自然換髮型需同時處理舊髮移除、新髮生成及原先被遮住區域的重建。簡單貼圖與色塊填補不再作為達成此需求的方案。

## 尚未授權的動作

「請繼續」按原隱私要求進行查閱與評估，不視為取消照片不上傳的限制。尚未上傳照片、呼叫付費推論、建立 GPU 服務或合併 PR。選定方案後，先核實政策與費用並準備具體測試範圍，再取得所需授權。
